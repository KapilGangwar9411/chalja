# Spectrum Admin Dashboard

A modern admin dashboard for managing user join requests and community interactions. Built with React and Firebase.

## Features

- User join request management
- WhatsApp group integration
- Real-time statistics
- Mobile-responsive design
- Admin and Super Admin roles
- Secure authentication

## Tech Stack

- React.js
- Firebase (Authentication & Realtime Database)
- CSS3 with modern design principles
- WhatsApp Business API integration

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Firebase account
- WhatsApp Business API access

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/spectrum-admin.git
cd spectrum-admin
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Create a `.env` file in the root directory and add your Firebase configuration:
```
REACT_APP_FIREBASE_API_KEY=your_api_key
REACT_APP_FIREBASE_AUTH_DOMAIN=your_auth_domain
REACT_APP_FIREBASE_DATABASE_URL=your_database_url
REACT_APP_FIREBASE_PROJECT_ID=your_project_id
REACT_APP_FIREBASE_STORAGE_BUCKET=your_storage_bucket
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
REACT_APP_FIREBASE_APP_ID=your_app_id
```

4. Start the development server:
```bash
npm start
# or
yarn start
```

## Usage

1. Access the admin dashboard at `http://localhost:3000/admin`
2. Log in with admin credentials
3. Manage join requests and user interactions
4. Approve/reject requests and add users to WhatsApp group
